** A NoSQL database is non-relational data management system that uses flexible schemas to handle large volume of unstructured and semi-structured data **

NoSQL databases offer horizontal scalability , high performance and develop for agile development of modern applications 

Types of NoSQL databases :-

  *** Document databases **

How data is stored :-  data is saved as documents(JSON / BSON / XML )  | each document can have different fileds and nested structures 
Examples of this types of database - mongoDB , couchBase , Amazon documentdb

  ** key-value stores **
  
How data is stored :- data is stored as key value pairs 
Examples - Redis / AmazonDynamoDB

  
 **  wide-column stores**
 
how data is stored - data are stored in rows and flexible columns 
Examples - cassandra / HBase

  ** graph databases **

how data is stored - data is stored as nodes and edges 
Examples - Neo4j / Amazon Neptune / ArangoDM
