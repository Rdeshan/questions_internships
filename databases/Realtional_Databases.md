relational - related to each tables 

**  Relational databases mean organize data into structured tables with rows and columns , using predefined relationships to link related data across different tables **

use SQL commands for manage the database

Key components - tables , rows , columns , keys 

ACID compilance ---------------------------------------------------------

  Atomicity - Transactions are all or nothing , if one part failed all transaction is rolled back   
  Consistency - Data must meet all validation rules to be saved to the database 
  Isolation - transactions are independent and do not interface with each other 
  Durability -  Once a transaction is commited, it remains saved even in the event of a system failure


Popular database management systems -

  MySQL , PostgreSQL , Microsoft SQL server , Oracle database
