### Why is database-normalization/data normalization important ### [IBM-Report](https://www.ibm.com/think/topics/database-normalization#:~:text=Database%20normalization%20is%20a%20database,redundancy%20and%20bolster%20query%20performance.)
		
		* data normalization—helps businesses and institutions more effectively organize
		* query and maintain large volumes of complex, interrelated and dynamic data.
		* when data records are related to each other in a database structure, changes to single values or rows in a large,
		complicated table might yield unintended consequences—such as data inconsistency and data loss.
		Database normalization is designed to minimize such risks.
		
		
### Benefits of database-normalization ###

		* Prevention of data anomaly (insert , update , delete anomalies)
		* Reduction of unintentional data redundancy
		* Data Storage cost Savings
		* faster data retrieval	(low-redundancy -> less data process -> faster-queries -> fast data searching )
